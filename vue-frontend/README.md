# 🎨 Frontend — Vue

The part you actually look at.

## What you need

- 🟢 Node 22.12+
- npm

## Running it

```powershell
npm install
npm run dev
```

Opens up at `http://localhost:5173` ✨

⚠️ This needs the backend running too! Make sure `springboot-backend` is up on `http://localhost:8080` before loading the app, or you'll just get a friendly error message instead of books. 😅
## Building for real

```powershell
npm run build
```
